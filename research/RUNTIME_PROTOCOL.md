# Runtime Protocol

사용자는 실제 APK 실행 담당자다.

## Codex가 제공할 것
- 설치 명령
- 실행 후 확인할 화면
- 기대 결과
- 실패 시 `adb logcat`에서 볼 태그/키워드
- 필요하면 스크린샷 위치/파일명

## 사용자가 보고할 것
최소한 다음 형식으로 GPT에게 전달한다.

```text
APK: <build id 또는 sha256>
설치: 성공/실패
실행: 성공/실패
마지막으로 본 화면: <설명>
버튼 반응: <설명>
업데이트 메시지: <있음/없음 + 문구>
앱 종료/크래시: <예/아니오>
추가 logcat: <있으면 붙여넣기>
```

## 원칙
런타임 결과는 정적 분석보다 우선한다. 다만 한 번의 실행 결과만으로 원인을 단정하지 않고, GPT가 필요한 추가 실험을 지정한다.
